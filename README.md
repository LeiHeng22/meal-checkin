# 每日打卡

手机和电脑打开同一页：看当天吃什么、练什么，勾完写入这个仓库的 `data/checkins.json`。

页面：https://leiheng22.github.io/meal-checkin/

仓库是公开的，勾选、体重和备注提交后，能在 GitHub 上看到。备注里不要写密码。

## 两台设备都能记

令牌只保存在那台设备的浏览器里，不会写进仓库。

1. 打开页面，点「连接 GitHub」。
2. 按页面上的步骤新建令牌，权限只要这个仓库的 Contents 读写。
3. 粘贴后点「保存令牌」。
4. 电脑、手机各做一次。

之后勾选会提交到 `data/checkins.json`。另一台打开页面就会拉到最新记录。
